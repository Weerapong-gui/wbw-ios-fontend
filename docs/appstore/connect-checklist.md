## Connect metadata

- [ ] **Privacy Nutrition Label** — ตั้งให้ตรงกับ `WBW/PrivacyInfo.xcprivacy`
      **เป๊ะ ๆ** ตอนนี้ประกาศ 5 ประเภท ทุกตัวผูกกับตัวตน (`Linked = true`) ไม่มีตัวไหน
      ใช้เพื่อติดตาม (`Tracking = false`) และวัตถุประสงค์เป็น App Functionality ทั้งหมด:

      | ประเภทใน manifest | ตอบใน ASC ว่าคืออะไร |
      |---|---|
      | `UserID` | รหัสนักศึกษาที่ใช้เข้าสู่ระบบ |
      | `Name` | ชื่อบนบัตรผู้เข้าร่วมและในแชท |
      | `OtherUserContent` | ข้อความในแชทกลุ่ม + ความเห็นต่อฐาน |
      | `DeviceID` | device token สำหรับ push |
      | `PreciseLocation` | พิกัดตอนกดปุ่ม SOS เท่านั้น |

      `NSPrivacyTracking = false` และ `NSPrivacyTrackingDomains` ว่าง → ตอบ **No**
      ที่คำถามเรื่อง tracking · **ห้ามเพิ่มประเภทที่ manifest ไม่มี** และห้ามลดด้วย
      Apple เทียบสองอย่างนี้กับหน้าเว็บนโยบาย (ข้อ 9 ของนโยบาย) เอง

      **ข้อมูลสุขภาพไม่ต้องประกาศ** เพราะแอปไม่ได้เก็บ ผู้ใช้กรอกบนเว็บลงทะเบียน
      แอปแค่แสดง — ตรวจแล้วว่าไม่มี endpoint ไหนในแอปเขียนข้อมูลสุขภาพ
      (`WBW/APIClient.swift`) · ถ้าตัดสินใจตอบว่าเก็บ ต้องเพิ่มใน manifest ก่อน
      ซึ่งเป็นการแก้โค้ด ไม่ใช่แก้แค่แบบสอบถาม

- [ ] **สกรีนช็อต** — 10 ใบ × 2 ขนาด อยู่ที่ `docs/appstore/screenshots/6.5/`
      (1242×2688) และ `/6.9/` (1320×2868) ถ่ายใหม่ทั้งชุด 2026-08-22 จากโหมดเดโม่
      · **อัปโหลดต้องทำมือ** เมนู Previews and Screenshots → "View All Sizes in
      Media Manager" · โฟลเดอร์นี้อยู่ใน `.gitignore` ไฟล์จึงมีแค่บนเครื่องที่ถ่าย
      ถ้าย้ายเครื่องต้องถ่ายใหม่ตามขั้นตอนใน `docs/appstore/README.md`

- [ ] **App description ต้องมีประโยคเรื่อง SOS** — แอปอยู่หมวด Health & Fitness
      ซึ่ง Apple อ่านละเอียดที่สุดเรื่องการอ้างความสามารถทางการแพทย์/ฉุกเฉิน
      ใส่ประมาณนี้: *"ปุ่มขอความช่วยเหลือฉุกเฉินในแอปแจ้งทีมงานของกิจกรรม
      ไม่ใช่การเรียกหน่วยกู้ชีพ ในกรณีฉุกเฉินจริงโปรดโทร 1669"* ·
      ข้อความเดียวกันนี้อยู่บนจอสถานะ SOS ในแอปแล้ว (คีย์ `sos_not_emergency_service`)
      สองที่ต้องพูดตรงกัน

- [ ] **Age rating** — ไม่มีเนื้อหาที่ต้องเรตติ้ง → 4+ · แต่ดูข้อ "ผู้เยาว์" ด้านล่าง
      ก่อนตอบแบบสอบถาม

- [ ] **Demo Account** ในหน้าเวอร์ชัน — `6939999999` / `WbwReview2026!`
      ค่าเดิมที่ Apple ถืออยู่ใช้ได้แล้ว ไม่ต้องแก้ ถ้าไม่ได้เปลี่ยนรหัส

## ข้อที่ต้องมีคนตัดสิน ไม่ใช่ช่องกรอก

- [ ] **ผู้เข้าร่วมอายุต่ำกว่า 20 ปี** — ตรวจ DB จริงแล้ว: ตาราง `consent` มีแค่
      `consent_health_data`, `consent_emergency_treatment`, `waiver_accepted`
      **ไม่มีคอลัมน์ความยินยอมของผู้ปกครองเลย** ทั้งที่ `date_of_birth` มีอยู่จึงรู้อายุ
      · ข้อ 8 ของนโยบายจึงเขียนว่าผู้จัดดำเนินการนอกระบบลงทะเบียน ซึ่งเป็นความจริง
      ตามที่ระบบเป็นอยู่ · **ถ้าจะเปลี่ยนไปเขียนว่าเว็บเก็บความยินยอมผู้ปกครอง
      ต้องมีขั้นตอนนั้นจริงและเก็บหลักฐานก่อน** ไม่ใช่แก้แค่ข้อความ

- [ ] **ลิงก์นโยบายในหน้าตั้งค่าของแอป** — ตอนนี้ **ไม่มีเลยสักจุด**
      (`WBW/SettingsView.swift` หมวด "ทั่วไป" มีแค่ เกี่ยวกับงาน / ช่วยเหลือ /
      เครดิต / ออกจากระบบ) · ไม่ใช่ข้อบังคับของ Apple สำหรับแอปที่ไม่มีบัญชีสมัคร
      ในแอป แต่เป็นสิ่งที่ผู้ตรวจมองหา · พอมี URL แล้วให้เพิ่มเป็น `Link` ออกเว็บ
      **ไม่ใช่ `DocView` ที่ฝังข้อความ** — ฝังแล้วแก้นโยบายทีไรต้องส่งแอปใหม่ทุกครั้ง
