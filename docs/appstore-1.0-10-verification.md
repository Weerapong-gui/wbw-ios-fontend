## 5. บั๊กที่เจอระหว่างทำงานนี้ และแก้ไปแล้ว

**โหมดเดโม่ยังเด้งกล่องขอตำแหน่ง** — `Session.startDemo()` ตั้งใจไม่ขอสิทธิ์ด้วยเหตุผลนี้ตรง ๆ
มาตั้งแต่แรก แต่ `SOSStatusView.onAppear` เรียก `requestPermissionIfNeeded()` เองอีกทาง ผู้รีวิว
ที่กดปุ่ม SOS ในโหมดเดโม่จึงยังเจอกล่องอยู่ดี · ประตูย้ายไปอยู่ที่ `SOSLocator` จุดเดียว

**เทสที่เขียวทั้งที่ตรวจอะไรไม่ได้เลย** — ตัวกวาดพื้นที่รับนิ้วเขียนผิดสองรอบและ**เขียวทั้งสองรอบ**:
รอบแรกหน้าต่าง N บรรทัดตายตัวตัดกลางปุ่มจนหาเจอ 2 ตัวจากทั้งแอป รอบสอง guard `Label(` ดันไป
แมตช์คำว่า `accessibilityLabel` เอง ปุ่มที่ติดป้ายถูกแล้วเลยถูกข้ามหมด เหลือตรวจได้จริงปุ่มเดียว
· จึงมีเทสคู่ที่นับจำนวนที่กวาดเจอไว้ด้วย (`testTheSweepActuallyFindsIconOnlyButtons`) — ทรงเดียว
กับที่ `LocalizationDashTests` ทำอยู่แล้ว

**`git add` ทีละไฟล์ยังไม่พอ — ไฟล์เดียวก็มีงานสองเจ้าของได้** commit a11y รอบแรกดึงงาน
ที่ยัง uncommitted อยู่ใน `Map3DScreen.swift` (ฟีเจอร์วงแสงหมุด `spotlightSequence`) ติดไป
ด้วยทั้งก้อน — 9 จาก 10 hunk ในไฟล์นั้นไม่ใช่ของงานนี้เลย · กติกาข้อ 7 เขียนว่าห้าม
`git add -A` ซึ่งทำตามแล้ว แต่กับดักจริงอยู่ลึกกว่านั้น: **ไฟล์ที่ตัวเองแตะอาจมีงานของคนอื่น
ค้างอยู่ในไฟล์เดียวกัน** ต้องดู `git diff <ไฟล์>` ก่อน add ทุกครั้ง ไม่ใช่แค่เลือกชื่อไฟล์
· แก้ด้วยการเขียน history ใหม่ (สาขายังไม่ push) โดยมี tag `backup/before-a11y-split-20260822`
สำรองไว้ · ยืนยันหลังแยกแล้ว: commit a11y ตัวใหม่ build ผ่านเดี่ยว ๆ โดยไม่ต้องพึ่ง WIP,
`git diff <tag>` เหลือเฉพาะ WIP ที่ยัง uncommitted อยู่เดิม ไม่มีอะไรหาย, และเทส 502 ตัวยังผ่าน

**สถานะซิมูเลเตอร์ค้างหลอกให้ไล่หาสาเหตุผิด** — `-uitestNotifications` ไม่เปิดชีตอยู่สองรอบ
ทั้งที่โค้ดถูก หายไปเองหลัง `simctl erase` · ตรงกับกับดักเดิมที่ `build-and-run.md` จดไว้แล้ว

## 8. รันบนเครื่องจริงแล้ว — iPhone 13, 2026-08-22

**ข้อค้างที่ใหญ่ที่สุดของรอบนี้ปิดแล้ว** เครื่องจริงตัวแรกที่แอปนี้เคยรันนับตั้งแต่ merge SOS

| ตรวจอะไร | ผล |
|---|---|
| build + เซ็นสำหรับเครื่องจริง | `** BUILD SUCCEEDED **` (Apple Development, team `NJL4K64JX5`) |
| ติดตั้งผ่าน `devicectl` | สำเร็จ · `.app` 28 MB |
| **`map.usdz` โหลดบนแท็บ Map** | **3.84 วินาที** — `[Map3DScreen] โหลด map.usdz เสร็จใน 3.84 วิ` |
| หมุดฐาน | `ติดปุ่มแตะให้หมุดได้ 16 จาก 16 ชื่อ` |
| อยู่บนแท็บแผนที่ 60 วินาที | process ไม่ตาย ไม่มี jetsam |
| ไล่ครบทุกแท็บ (`-uitestTabSequence`) 60 วินาที | ไม่ crash · long-poll แชทเดินปกติ |
| crash report | ไม่มีไฟล์ของ WBW เลย |

**ตัวเลขที่พลิกสมมติฐาน:** ก่อนหน้านี้บันทึกไว้ว่าแผนที่ 3D เป็นความเสี่ยง crash เพราะบนซิมูเลเตอร์
ต้องรอ 40 วินาที (6.5) ถึง 90 วินาที (6.9) กว่าจะโหลดเสร็จ · บนเครื่องจริงใช้ **3.84 วินาที** —
ช้ากว่า 10–20 เท่าคือ **ซิมูเลเตอร์เอง** ไม่ใช่ตัวโมเดล (ซิมเรนเดอร์ Metal ผ่าน CPU ของ Mac)
สรุป: `Config.map3D = true` ไม่ต้องปิด

**ข้อจำกัดของหลักฐานนี้ที่ต้องพูดตรง ๆ:** iPhone 13 คือ A15 / RAM 4 GB **ไม่ใช่เครื่องต่ำสุดที่
iOS 18 รองรับ** (iPhone XR/XS = A12 / RAM 3 GB) · ผลนี้จึงแปลว่า "ไม่ใช่ปัญหาบนเครื่องระดับกลาง"
ไม่ใช่ "ปลอดภัยทุกเครื่อง"

**ที่ยังไม่ได้วัดบนเครื่องจริง:** ความแม่นของ GPS กับพฤติกรรมตอนขอสิทธิ์ตำแหน่งจริง — ทั้งสอง
อย่างต้องล็อกอินบัญชีจริงด้วยมือก่อน เพราะโหมดเดโม่ถูกกันไม่ให้ขอสิทธิ์โดยตั้งใจ (ดูข้อ 1)
