# หน้าจับกลุ่ม — Liquid Glass บนพื้นทึบ

> **แก้ 2026-08-07:** สเปกนี้เขียนตอนพื้นหลังยังเป็นฉากป่า 3D ตอนนี้ฉากถูกปิดด้วย
> `Config.forest3D` (ดู `2026-08-07-forest-3d-off-design.md`) `.forestBackground()` ยังเป็น
> ตัวเดิมที่ต้องเรียก แต่มันวาดพื้นทึบ `Color.wbwForestVoid` (#0A1610) ให้แทนฉาก
> การ์ด liquid glass และเนื้อหาอื่นคงเดิมทั้งหมด

**เป้าหมาย:** เปลี่ยนหน้าจับกลุ่มจากพื้นครีมทึบ + การ์ดขาวทึบ ให้เป็นการ์ด Liquid Glass ลอยบนพื้นทึบ #0A1610
ตัวเดียวกับที่ Home / Login / QR ใช้ พร้อมหัวข้อใหญ่สองบรรทัดและปุ่มเข้ากลุ่มขาวทึบตัวหนังสือเขียว

**ที่มา:** ภาพ mockup ที่ Park ส่งเมื่อ 2026-08-06 ("Choose your Adventure group") บรีฟสามข้อคือ
การ์ดกลุ่มเป็น liquid glass, พื้นหลังใช้แบบเดียวกับหน้าอื่น, และปุ่ม join

**ขอบเขต:** `WBW/GroupJoinView.swift` ไฟล์เดียว 155 บรรทัด ไม่สร้างไฟล์ใหม่ ไม่แตะ `GroupStore`
ไม่แตะ API ไม่แตะ `GroupHomeView` / `GroupMembersView` ตรรกะ join, ค้นหา, จัดการ error เดิมคงไว้ครบ
เปลี่ยนเฉพาะชั้นการแสดงผล

**สาขา:** `feature/redesign-group-chat` (ชื่อสาขาไม่ตรงกับงาน — สาขาถูกตั้งก่อนรู้ว่าเป้าหมายจริงคือ
หน้าจับกลุ่ม ไม่ใช่หน้าแชท เก็บชื่อเดิมไว้เพราะ push ขึ้น origin แล้ว)

## 1. สิ่งที่มีอยู่แล้วและจะนำมาใช้

ไม่ต้องสร้างพื้นฐานใหม่ ทั้งสองชิ้นอยู่ใน main แล้ว:

| ของที่มี | ที่อยู่ | หน้าที่ |
|---|---|---|
| `.glassSurface(_ shape:, interactive:)` | `WBW/GlassSurface.swift` | Liquid Glass เนทีฟบน iOS 26 · fallback `.ultraThinMaterial` + เส้นขอบขาว 60% บน iOS 18-25 |
| `.forestBackground(day:plantStep:plantTotal:bottomClearance:)` | `WBW/Scene3D/ForestSceneHost.swift:196` | พื้นหลังร่วมของ `HomeView`, `LoginView`, `MyQRCodeView` — วาดพื้นทึบตอน `Config.forest3D` ปิด |

deployment target คือ iOS 18.0 ดังนั้น `glassEffect` เรียกตรง ๆ ไม่ได้ ต้องผ่าน `glassSurface`
ซึ่ง gate ด้วย `#available(iOS 26.0, *)` ไว้แล้ว

พารามิเตอร์ของ `forestBackground` สำหรับหน้านี้:

- `day: ForestMath.dayStill` — เหมือน `LoginView` / `MyQRCodeView` (หน้าที่ไม่ผูกกับความคืบหน้าเช็คอิน)
- `plantStep:` ไม่ส่ง (= `nil`, ไม่มีต้นไม้) — มีแค่ `HomeView` ที่ส่งต้นไม้
- `bottomClearance:` ไม่ส่ง (= `ForestSceneHost.tabBarClearance`) — หน้านี้อยู่ใต้แท็บบาร์ลอยของ `MainTabView`

## 2. โครงหน้าใหม่

ภาษาไทยทั้งหน้า (mockup เป็นอังกฤษ แต่ทั้งแอปเป็นไทย — หน้านี้ต้องไม่แปลกแยก)

### 2.1 พื้นหลัง

ถอด `private let bg = Color(red: 250/255, green: 247/255, blue: 240/255)` และ `bg.ignoresSafeArea()`
ใน `ZStack` ออก ใส่ `.forestBackground(day: ForestMath.dayStill)` แทน

### 2.2 หัวจอ

เดิมปุ่มย้อนกลับกับช่องค้นหาอยู่แถวเดียวกัน (`HStack`) ใหม่แยกเป็นสามชั้น เพราะหัวข้อใหญ่ต้องการ
ความกว้างเต็ม:

```
◀                              ← ปุ่มกลม 40×40 glass interactive
                                 (เดิม Color.white in Circle)

เลือก                           ← 15pt regular · ขาว 75%
กลุ่มของคุณ                      ← 32pt heavy · ขาว

🔍 ค้นหากลุ่ม หรือ ชื่อเพื่อน       ← แคปซูล glass · ตัวขาว
                                 (เดิม Color.white in Capsule)
```

ข้อความ placeholder ของ `TextField` ต้องอ่านออกบนกระจก — ใช้ `.foregroundStyle(.white)` บนตัว
`TextField` และกำหนดสี placeholder เองผ่าน `Text` ที่มี `.white.opacity(0.6)` เพราะ placeholder
เริ่มต้นของ SwiftUI ใช้สีระบบที่จางเกินไปบนพื้นเข้ม ไอคอนแว่นขยายเปลี่ยนจาก `.secondary` เป็น
ขาว 70%

### 2.3 การ์ดกลุ่ม

เนื้อในเหมือนเดิมทุกอย่าง — วงกลมเลขกลุ่ม, ชื่อกลุ่ม, avatar สมาชิกซ้อน 4 คน, `45/50`,
ปุ่มเข้ากลุ่ม, แตะที่ตัวการ์ดไปหน้าสมาชิก เปลี่ยนเฉพาะสีและพื้น:

| จุด | เดิม | ใหม่ |
|---|---|---|
| พื้นการ์ด | `Color.white` ทึบ ใน `RoundedRectangle(cornerRadius: 16)` | `.glassSurface(RoundedRectangle(cornerRadius: 16))` |
| ชื่อกลุ่ม | `Color.wbwInk` | `.white` |
| `45/50` | `.secondary` | `.white.opacity(0.75)` |
| วงเลขกลุ่ม | `Circle().fill(Color.wbwGold.opacity(0.15))` + เลข `wbwGold` | `Circle().fill(.white.opacity(0.20))` + เลขขาว |
| ปุ่มเข้ากลุ่ม | `Color.wbwGold` ตัวขาว | `Color.white` ทึบ ตัว `Color.wbwGreen` |
| ปุ่มตอนเต็ม | `Color.gray` ตัวขาว | `.white.opacity(0.25)` ตัว `.white.opacity(0.6)` |
| spinner ตอนกำลังเข้า | `.tint(.white)` | `.tint(Color.wbwGreen)` (อยู่บนปุ่มขาวแล้ว) |

วงเลขกลุ่มต้องเปลี่ยนสีเพราะทองที่ opacity 15% บนกระจกใสทับป่าเขียวแทบมองไม่เห็น — นี่คือเรื่อง
อ่านออก ไม่ใช่เรื่องรสนิยม

### 2.4 ส่วนอื่นบนหน้าเดียวกัน

ต้องตามไปด้วย ไม่งั้นจะเหลือของขาวทึบโดดอยู่กลางจอกระจก:

- `peopleSection` (การ์ดผลค้นหาคน) — พื้น `Color.white` → `.glassSurface(RoundedRectangle(cornerRadius: 14))`,
  ชื่อคน `wbwInk` → ขาว, "กลุ่ม N" และหัวข้อ "คนที่พบ" `.secondary` → ขาว 75%
- `"ไม่พบกลุ่ม"` — `.secondary` → ขาว 75%
- แถบ error แดง — คงเดิม อ่านออกบนทุกพื้นอยู่แล้ว

### 2.5 ระยะล่างลิสต์

`.padding(16)` รอบเดียวไม่พอให้การ์ดใบสุดท้ายพ้นแท็บบาร์ลอย (ในภาพ mockup เองก็เห็นการ์ด Group 8
โดนทับครึ่งใบ) เพิ่ม `.padding(.bottom, ForestSceneHost.tabBarClearance)` ที่ `LazyVStack`
ค่านี้คือระยะพ้นแท็บบาร์ลอยที่วัดจากเครื่องจริงสองรุ่น (ดูคอมเมนต์ที่ `ForestSceneHost.tabBarClearance`)
ยังใช้ได้เหมือนเดิมแม้ฉากป่าจะถูกปิดไปแล้ว

## 3. ความเสี่ยง

### 3.1 ความเสี่ยงเดิมที่หายไปทั้งคู่

ฉบับก่อนมีความเสี่ยงสองข้อ: `NavigationStack` ทับฉากป่าจนพื้นดำ และ `claimScene()`/
`releaseScene()` ส่งไม้ต่อไม่ทันตอน push ไป `GroupMembersView` จนฉากหายกลางทาง
ทั้งคู่ผูกกับฉาก 3D ที่ `RootView` ซึ่งอยู่คนละ hosting context กับจอ ตอนนี้ฉากไม่ถูก mount
แล้ว พื้นหลังถูกวาดใน `.background` ของจอเอง — อยู่ต้นไม้เดียวกับจอ ไม่มีอะไรให้ทับหรือ
หลุดมือได้อีก แผนถอย 3 ขั้นและการถอด `NavigationStack` จึงไม่ต้องใช้แล้ว

### 3.3 `.ultraThinMaterial` บน iOS 18-25

fallback ของ `glassSurface` เบลอสิ่งที่อยู่หลังมัน ซึ่งตอนนี้คือพื้นทึบสีเดียวในกรอบเดียวกับการ์ด
material จะได้สีเดียวสม่ำเสมอ ไม่ใช่ลายป่า — ยังต้องดูด้วยตาว่ามันไม่กลายเป็นแผ่นเทาที่กลืนกับพื้นจนมองไม่เห็นขอบการ์ด

`GlassRing` ใน `HomeView` ใช้แพทเทิร์นเดียวกันและอยู่บน production แล้ว จึงน่าจะผ่าน แต่วงแหวนเล็ก
กับการ์ดเต็มใบขนาดต่างกันมาก ต้องดูบนซิมที่ตั้ง iOS 18 ด้วย ไม่ใช่ดูแค่ 26

### 3.4 ตัวหนังสือขาวบนส่วนสว่างของฉาก

`dayStill` ตรึงเวลาไว้ ความสว่างรวมจึงคงที่ แต่ในฉากยังมีทั้งส่วนสว่าง (ฟ้า) และมืด (ไม้) การ์ดมี
กระจกรองอยู่แล้ว หัวข้อใหญ่ไม่มี ถ้าหัวข้อไปตกตรงฟ้าสว่างจะอ่านไม่ออก — ถ้าเจอ ใส่ scrim
`LinearGradient` ดำจาง ๆ (opacity 0.35 → 0) สูงประมาณหัวจอ ใต้ข้อความ

### 3.5 รอยต่อไป `GroupHomeView` — รับไว้โดยตั้งใจ

`GroupTabView` สลับสองหน้าบนแท็บเดียว: ยังไม่เข้ากลุ่ม = `GroupJoinView` / เข้าแล้ว = `GroupHomeView`
พอกดเข้ากลุ่มสำเร็จ จอจะเด้งจากป่า+กระจกไปเป็นครีมทึบทันทีในเฟรมเดียว

ไม่แก้ในงานนี้ ผู้ใช้เห็นรอยนี้ครั้งเดียวตอนกดเข้ากลุ่มสำเร็จ แล้วไม่เห็นอีกตลอดงาน (เข้ากลุ่มแล้ว
ไม่ได้ออก) การทำ `GroupHomeView` ให้เข้าชุดต้องออกแบบปุ่ม "เปิดแชทกลุ่ม" การ์ด "สมาชิกในกลุ่ม" และ
ปุ่มออกจากกลุ่มใหม่ทั้งชุด ซึ่งเกินบรีฟ ถ้าทำทีหลังไม่มีอะไรต้องรื้อจากงานนี้

## 4. การยืนยัน

เทสในโปรเจกต์เป็น unit test ล้วน 133 ตัว ไม่มี UI test ไม่มี snapshot test งานนี้เปลี่ยนภาพล้วน
เขียนเทสอัตโนมัติที่พิสูจน์ผลลัพธ์ทางสายตาไม่ได้ จะไม่เพิ่มเทสที่ไม่ได้พิสูจน์อะไรเพื่อให้ตัวเลขดูดี

ยืนยันสองชั้น ต้องผ่านทั้งคู่:

1. **กันพัง** — `xcodegen generate && xcodebuild test -scheme WBW -destination 'platform=iOS Simulator,name=iPhone 17'`
   ต้องได้ 133/133 เท่าเดิม พิสูจน์ว่าการแก้ไม่ไปทำอย่างอื่นพัง
2. **ดูด้วยตา** — รันบนซิมูเลเตอร์ เก็บภาพจริง 4 สถานะ แล้วแนบให้ดู ไม่ใช่รายงานว่าผ่าน:
   - ลิสต์กลุ่มปกติ
   - ค้นหาแล้วเจอคน (`peopleSection` โผล่)
   - กลุ่มที่เต็ม (ปุ่มสถานะเต็ม)
   - กำลังกดเข้ากลุ่ม (spinner บนปุ่ม)

   แล้วรันซ้ำบนซิมที่ตั้ง iOS 18 เพื่อดู fallback `.ultraThinMaterial` โดยเฉพาะ

ความเสี่ยงเรื่องป่าหายตอนเดินเข้าหน้าสมาชิกหมดไปแล้ว (ดู §3.1) — ไม่ต้องมีขั้นตอนนี้อีก
