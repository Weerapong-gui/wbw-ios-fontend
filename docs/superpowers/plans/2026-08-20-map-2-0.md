# แผนที่ 2.0 Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** เอา `Map2.0.usdz` แทนโมเดลแผนที่ใบเดิมทั้งใบ แล้วปรับลำดับหมุด การแตะ พิกัดจุด GPS ท้องฟ้า และเมฆ ให้ตรงกับใบใหม่

**Architecture:** ค่าทุกตัวที่ผูกกับไฟล์โมเดลอยู่ใน `WBW/Resources/map_config.json` ไฟล์เดียว (`Map3DConfig` อ่านเข้ามา พร้อม `fallback` ที่คอมไพล์ติดไปด้วย) งานนี้เปลี่ยนสคีมาไฟล์นั้นสามจุด: หมุดรับชื่อ prim ได้หลายชื่อต่อฐาน, กรอบ `bounds` lat/lng ถูกแทนด้วย `anchor` (origin + หน่วยต่อองศา) เพื่อเลิกพึ่ง `visualBounds` ของทั้งโมเดล, และ `sky` ตัด `apronSpanMultiplier` ทิ้งพร้อมม่านขอบ

**Tech Stack:** SwiftUI · RealityKit · XCTest · XcodeGen (ไม่ต้องรันรอบนี้ ไม่มีไฟล์เพิ่ม/ลบใน `WBW/`)

**Spec:** `docs/superpowers/specs/2026-08-20-map-2-0-design.md`

## Global Constraints

- **ห้าม `git add -A` / `git add .`** — repo นี้มักมีงานอื่นที่ยัง untracked วางอยู่ข้าง ๆ `git add` ทีละไฟล์เสมอ
- **ห้าม commit `WBW/Config.swift` บรรทัด `Config.backend`** — ค่าที่ค้างตอน push คือค่าที่ขึ้น store จริง
- **ห้ามให้เทสใดโหลด `map.usdz`** — เทสยูนิตรันในโปรเซสเดียวกับแอป โหลด USD stage ค้างตอน `exit()` แล้ว `EXC_BAD_ACCESS` (มี crash report จริง 2026-08-20) · `Map3DScreen.shouldRender(map3D:underTest:)` เป็นตัวกัน อย่าแก้
- **เขียนเทสที่ fail ก่อน แล้วค่อยเขียนโค้ดให้ผ่าน (TDD)**
- **คอมเมนต์และ commit message เป็นภาษาไทย บอก "ทำไม" ไม่ใช่ "ทำอะไร"** — โค้ดบอกว่าทำอะไรอยู่แล้ว สิ่งที่ขาดคืออาการที่จะเจอถ้าทำผิดทาง
- **ห้ามเคลมว่างานเสร็จโดยไม่ได้รันจริง** — งานที่แตะ UI ต้องมีสกรีนช็อตจาก simulator ประกอบเสมอ
- **ข้อความที่ผู้ใช้เห็นต้องผ่านชุดคีย์** — นอก View ใช้ `Loc.t("key")` ไม่ใช่ `String(localized:)` (แผนนี้ไม่เพิ่มข้อความใหม่ แต่ห้ามเผลอฮาร์ดโค้ดตอนแก้)
- **ไม่ต้องรัน `xcodegen generate`** — ไม่มีไฟล์เพิ่ม ลบ หรือย้ายใน `WBW/`
- ค่าใน `Map3DConfig.fallback` ต้องตรงกับ `map_config.json` เป๊ะทุกตัว (`Map3DConfigFileTests.testShippedConfigMatchesTheCompiledFallback` คุมไว้)

```swift
    static func modelUnits(latitude: Double, longitude: Double,
                           in anchor: Map3DConfig.Anchor) -> SIMD2<Float>? {
        let x = (longitude - anchor.originLongitude) * anchor.unitsPerDegreeLongitude
        let y = (latitude - anchor.originLatitude) * anchor.unitsPerDegreeLatitude
        guard abs(x) <= anchor.halfSpanUnitsEastWest,
              abs(y) <= anchor.halfSpanUnitsNorthSouth else { return nil }
        return SIMD2<Float>(Float(x), Float(y))
    }
```

**Files:**

- Produces: ไม่มี API ใหม่

ไม่มีเทสยูนิตสำหรับขั้นนี้ — ต้องมีโมเดลจริงอยู่ในมือถึงจะมี `availableAnimations` ให้ตรวจ และกฎห้ามให้เทสโหลด `map.usdz` · ตัวยืนยันคือสองเฟรมจากจอจริง

- [ ] **Step 1: สั่งเล่นแอนิเมชันทุกตัวในโมเดล**

ใส่ต่อจากบรรทัด `root.addChild(map)` ใน `Map3DScreen`:

```swift
            // เมฆของ Map2.0 มีคีย์แอนิเมชันของ Blender ติดมา (stage 1…280 เฟรม ที่ 24 fps)
            // RealityKit ไม่เล่นให้เอง ต้องสั่ง · ไล่ทั้งต้นเพราะ Blender ยัดคีย์ไว้ที่ `cloud_*`
            // ทีละก้อน ไม่ใช่คลิปเดียวที่ราก — เรียกแค่ที่ `map` ตัวเดียวจะได้เมฆค้างนิ่งทั้งฟ้า
            //
            // ถ้า RealityKit ไม่แปลง timeSamples ให้เป็น availableAnimations ลูปนี้ก็ไม่ทำอะไรเลย
            // เมฆค้างนิ่ง แผนที่ยังใช้ได้ทุกอย่าง — เป็นข้อจำกัดที่ยอมรับไว้แล้ว ไม่ต้องเขียน
            // แอนิเมชันเองมาแทน (ดู docs/superpowers/specs/2026-08-20-map-2-0-design.md §8)
            var pending = [map]
            while let entity = pending.popLast() {
                for animation in entity.availableAnimations {
                    entity.playAnimation(animation.repeat())
                }
                pending.append(contentsOf: entity.children)
            }
```
